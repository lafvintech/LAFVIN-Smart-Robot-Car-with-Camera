The LAFVIN Smart Robot Car with Camera is an open-source DIY kit featuring real-time FPV video streaming and remote control via a mobile app. Powered by an ESP32-S3 module, OV3660 camera, and multiple sensors, it supports five intelligent modes: obstacle avoidance, line following, object following, IR control, and FPV transmission. By assembling and programming the car yourself, you can easily dive into robotics, electronics, and control systems.
